\section{Cuestionario}

\begin{enumerate}
    \item ¿Qué dos condiciones debe cumplir un problema para poder resolverse con Programación Dinámica?
    \item ¿Cuál es la diferencia principal entre memorización y tabulación?
    \item En la técnica SRTBOT, ¿qué garantiza específicamente el paso del orden topológico?
    \item ¿Por qué el problema de la diligencia puede tener más de una solución óptima?
    \item ¿Por qué aplicar Programación Dinámica a un algoritmo como Mergesort (Laboratorio 3) no traería ninguna mejora de eficiencia?
\end{enumerate}
